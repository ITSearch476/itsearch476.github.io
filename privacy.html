Zweck der Anwendung

IT Search verwendet eine lokal betriebene Postiz-Installation zur Planung und Veröffentlichung eigener Pinterest-Beiträge. Die Anwendung dient dem eigenen Gebrauch.

Verarbeitung von Daten

Für die Verbindung mit Pinterest können Kontoinformationen, Zugriffstoken, Pinnwandinformationen und Beitragsinhalte verarbeitet werden.

Datenspeicherung

Die Anwendungsdaten werden in der lokalen Postiz-Installation gespeichert. Zur Veröffentlichung werden erforderliche Daten an Pinterest übertragen.

Widerruf und Löschung

Die Pinterest-Verbindung kann widerrufen werden. Lokal gespeicherte Anwendungsdaten können gelöscht werden.

Hosting

Diese Informationsseite wird über GitHub Pages bereitgestellt. Dabei können technische Zugriffsdaten durch GitHub verarbeitet werden.
